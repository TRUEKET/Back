## 최신 합의와 초기 기획안의 차이

이번 기획안은 주의 2개부터 의심, 이름 불일치 신호(P1), 문자 소유 인증 등 초기 범위를 포함한다. 이후 대화에서 현재의 더 민감한 판정 유지와 v0.2 정책, demo 문자 방식이 명시적으로 선택됐다. 기획안만 보고 이를 되돌리지 않는다.

기획안 개인정보 정책은 판독 원문 삭제·가린 사진 최소 보관을 명시한다. 본인 신고 식별자 전체 표시는 사용자의 최신 직접 요청에 따라 본인 전용 조회로 한정한다. 원본 사진 공개 정책 변경으로 확대하지 않는다.

배포 초안과 트루샷 AI/CV·iOS 공유 바텀시트는 이번 수정 범위에 포함하지 않는다.
