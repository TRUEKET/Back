# 표현 변형·정상 문장 실제 AI 확인 (#84, 2026-11-19)

사용자가 인용문 형식뿐 아니라 사전 예시와 다른 표현의 신호 인식이 중요하다고 강조해 추가 확인했다. 기존에 지정한 OpenAI 키를 노출하지 않고 재사용했다. 로컬 127.0.0.1:18093의 임시 H2 서버에 개인정보 없는 합성 대화 PNG 4개를 POST /analyze로 전송했다. 팀 Supabase·Storage·SMTP·스케줄러·배포는 사용하지 않았다.

모든 응답의 dictionaryVersion은 v0.2였다. 채택된 인용은 실제 판매자 문장 구간을 사용했고 판독 ID는 각 요청 후 DELETE 204로 정리했다. 서버도 검증 후 종료했다.

이는 4개 합성 사례의 관측이며 정확도 평가나 모든 실제 캡처의 인식 보장이 아니다. 다른 표현의 의미를 인식하는 단계는 AI 추출이고, 인용문 검증 단계는 실제 원문 연속 구간과 공백·허용 문장부호 차이만 확인한다. 단어·숫자·부정 의미가 다른 인용을 sentenceId만으로 자동 인정하는 방식은 사용하지 않는다. 팀원이 문제가 생겼던 실제 캡처는 최신 서버로 새 판독해 별도 비교해야 한다.
