RP 신고 리스트·조회·등록·이의제기는 신고 담당자, TS 요청·촬영·공유는 트루샷 담당자 영역이다. 그 외 담당자가 구현할 부분은 판독에서 이 기능들을 호출하는 경계와 계정 탈퇴 시 함께 삭제하는 연결이다.

회원 탈퇴는 기존 DB의 트루샷 테이블을 사용하며 미병합된 트루샷 엔티티와 중복 정의하지 않았다. Storage 미설정 또는 파일 삭제 실패 시 503으로 중단한다. 다음 연결 우선순위는 신고 식별자 해시 계약과 실제 Gemini 호출 검증이다.
